#                   numpy._core.umath" from scipy.ndimage (measured 2026-08-01)
# So the notebook installs this file MINUS the line below. Everything excluded
# is either already in the Kaggle image or dev-only (never needed to train).
# Keeping the list here, rather than in a second requirements-kaggle.txt, is
# deliberate: a duplicate pinned file drifts from this one, and the failure
# mode of that drift is a dead GPU session.
#
